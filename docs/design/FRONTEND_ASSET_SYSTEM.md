# 前端图标、素材与动效规范

这份规范约束独立前端 `src/frontend-new/` 的视觉资产来源。目标是让界面保持统一、可维护，并避免重新出现字符图标、自绘临时图标和互不兼容的动效。

## 资产分工

| 类别 | 唯一来源 | 当前用途 |
|---|---|---|
| CartridgeFlow 品牌 | 项目自有 SVG | 左侧栏 Logo；这是独立前端唯一允许保留的自绘 SVG。 |
| 功能图标 | Lucide `1.26.0` | 导航、按钮、状态、搜索、刷新、关闭、文件和流程动作。 |
| 品牌与技术标识 | Simple Icons `16.27.0` | Python、Node.js、Git、FFmpeg、DeepSeek。 |
| 状态图形 | CSS 基础形状 | 成功、失败、等待的圆点，统计条和开关；它们表达数据，不冒充图标。 |
| 图表 | HTML + CSS 数据图形 | 概览运行活动等轻量统计；后续复杂图表再单独评估图表库。 |
| 交互组件 | Web Awesome `3.10.0` | Switch，以及后续按需接入的 Dialog、Select、Dropdown、Tooltip、Details。 |
| 交互动效 | Motion `12.42.2` | 页面进入、选择、弹窗、删除、折叠、Toast、刷新和设置预览。 |

四个第三方包都由 `package-lock.json` 锁定并从本地 `node_modules` 加载，不依赖 CDN。Lucide、Motion 与 Web Awesome 使用 MIT 许可，Simple Icons 使用 CC0-1.0。

Web Awesome 只使用免费的稳定组件，并通过 `dist-cdn` 自托管入口直接服务给原生 HTML。组件必须在 `component-system.js` 集中注册，禁止各页面自行散落导入。

## 使用规则

1. 新增功能图标时，先从 Lucide 选择语义最接近的线性图标，不加入 emoji、Unicode 箭头或临时字符。
2. 只有真实品牌或技术名称使用 Simple Icons；普通“模型”“工具”“文件夹”仍使用 Lucide。
3. 图标默认继承文字颜色。橙色只表达品牌和主操作，绿色、蓝色、红色只表达状态。
4. 纯图标按钮必须有 `aria-label`；图标与可见文字共同出现时，图标使用 `aria-hidden="true"`。
5. 不为单页引入完整 UI 框架，也不从网络热链图片、图标或字体。交互复杂的通用控件优先从 Web Awesome 按需导入。
6. 自定义插画需要单独评审。流程空状态优先组合成熟图标，不继续堆叠 CSS 线框图。
7. 页面骨架、业务卡片、统计图和步骤轨道保留项目设计；Dialog、Select、Dropdown、Switch、Tooltip、Details 等通用行为交给成品组件。

## 动效规则

- 页面进入：约 200ms，最多处理首批九个主要区块，位移不超过 5px。
- 选择反馈：约 170ms，只使用轻微透明度和缩放变化。
- 弹窗：打开约 220ms，关闭约 140ms；背景和面板同步。
- 删除：约 200ms，先收起再移除 DOM，避免列表突然跳动。
- 折叠：约 180ms，同步高度、透明度和箭头方向。
- Toast 与刷新：只提供短促反馈，不循环、不弹跳、不放大界面。

所有动效必须同时服从系统 `prefers-reduced-motion` 和设置页的“减少动效”开关。关闭动效时，状态变化仍然必须立即完成。

## 验收

每次新增图标或动效后至少检查：

1. 页面中所有 `data-lucide` 元素都已转换为 `svg.lucide`。
2. 品牌图标文件可由本地服务器读取。
3. 键盘可以操作关闭、折叠等交互。
4. 100% 和 125% 下页面级横向、纵向滚动均为 0。
5. 开启减少动效后，交互状态正确且不依赖动画完成。
